# Mahendra-Car-Tractor-sales-report
Mahindra Cars and Tractors Sales Analysis Dashboard built using Microsoft Power BI to visualize sales performance, vehicle models, city-wise revenue, discounts, payment methods, and key business KPIs through interactive charts and visualizations.

Mahindra Cars and Tractors Sales Dashboard 📊
Project Overview

This project is an interactive sales analysis dashboard developed using Microsoft Power BI to analyze Mahindra Cars and Tractors sales data. It provides meaningful insights into vehicle sales performance, revenue trends, discount distribution, and customer payment preferences.

Key Features
Vehicle Sales Analysis: Compare units sold across different vehicle models.
City-wise Performance: Analyze sales revenue and discount trends across cities.
Payment Method Analysis: Understand the distribution of payment methods, including bank finance, UPI, cash, credit cards, and debit cards.
Vehicle Category Analysis: Compare sales performance between Cars & SUVs and Tractors.
Key Performance Indicators (KPIs): Track units sold, unit prices, total sales value, discounts, and final unit prices.
Interactive Visualizations: Explore sales data through charts, graphs, and dashboard visuals.
Tools & Technologies
Microsoft Power BI
Data Visualization
Sales Data Analysis
Business Intelligence
Objective

The objective of this project is to transform raw sales data into meaningful business insights, helping users understand sales trends, compare vehicle performance, and support data-driven decision-making.
